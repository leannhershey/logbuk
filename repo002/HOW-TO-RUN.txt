HOW TO RUN repo001 (XAMPP / WAMP / Apache)
==========================================

Open this check-list whenever a page shows its own code or says "Object not found".


THE ONE RULE
------------
Always open the site through  http://localhost/...  and never as a file.

  WRONG   file:///C:/xampp/htdocs/repo001/pages/occupants.php
  RIGHT   http://localhost/repo001/pages/occupants.php

Why: a .php file on your hard disk is just text. Only Apache + PHP turn it into
a web page. Opened with file://, the browser has no PHP, so it shows you the
source code instead. That is true of every PHP site, not just this one.

Rule of thumb:
  file:///...   -> the browser shows the file
  http://...    -> the server runs the file

NOTE: index.html is plain HTML, so double-clicking it *does* work. Do not use
that as your entry point anyway - its links lead to .php pages, and those will
show source again. Start at http://localhost/repo001/ every time.


STEP BY STEP
------------
1. Put the folder here (final name must be repo001):

       C:\xampp\htdocs\repo001

   You should be able to see  C:\xampp\htdocs\repo001\index.html

2. Start BOTH services in the XAMPP Control Panel:

       Apache   -> Start
       MySQL    -> Start

   Apache is what serves the pages. MySQL is what the pages read.

3. Create the database. Open  http://localhost/phpmyadmin , go to the Import
   tab, choose  repo001/db/logbuk.sql  and press Go.
   (Command line alternative:

       cd C:\xampp\htdocs\repo001
       C:\xampp\mysql\bin\mysql -u root < db\logbuk.sql        )

   This one file builds the schema, all 6 tables, the view, both triggers,
   both stored procedures and the 9 demo occupants.

4. Check the login in  repo001\config\config.php

       XAMPP defaults:  host localhost, user root, password "" (empty)
       If you set a MySQL root password, put it in that file.

5. Open:

       http://localhost/repo001/            <- entry screen
       click Admin  ->  passcode admin123
       ->  http://localhost/repo001/pages/dashboard.html

   Direct link:  http://localhost/repo001/pages/occupants.php


IF YOU SEE A PAGE OF CODE
-------------------------
You are on file:// . Replace the address bar with the http:// address.
Missing "repo001" in the path is the second most common cause.


IF YOU SEE "Object not found" (404)
-----------------------------------
Apache is running, but the folder is not where it expects it.
Check that this exact file exists:

       C:\xampp\htdocs\repo001\index.html

The path is case sensitive on some systems. repo001, not Repo001 or REPO001.
Opening http://localhost/ shows the htdocs listing - look for repo001 there.


IF YOU SEE "Unable to connect" / "can't reach this page"
--------------------------------------------------------
Apache is not running. Start it in the XAMPP Control Panel.
If it refuses to start, port 80 is taken (usually by Skype, IIS, or Windows
"World Wide Web Publishing"). Either quit that program, or make Apache listen on
port 8080: XAMPP -> Apache -> Config -> httpd.conf -> "Listen 80" ->
"Listen 8080", then use http://localhost:8080/repo001/ .


IF THE PAGE LOADS BUT THE TABLE IS EMPTY OR SAYS THE DATABASE IS UNREACHABLE
---------------------------------------------------------------------------
Open the connection doctor first:

       http://localhost/repo001/pages/db-check.php

It checks PHP, the PDO MySQL driver, the MySQL port, the login, the database,
all 6 tables, the ENUM column, the seed rows, the procedures and the triggers,
and prints the fix under whichever row fails.

The occupant list also names the likely cause instead of raw SQL:

  [1045] Access denied      MySQL refused the login -> set DB_PASS in
                            repo001\config\config.php to match your root password
                            (XAMPP default is empty: define('DB_PASS', ''); )
  [1049] Unknown database   step 3 was skipped -> import repo001\db\logbuk.sql
  [2002] Connection refused MySQL is not started -> Start it in XAMPP

You also need to be logged in: /pages/occupants.php redirects to the passcode
screen (index.html#admin, passcode admin123) when there is no admin session.
That redirect is normal, not an error.


IF THE PAGE HAS NO STYLING OR NO ICONS
--------------------------------------
The CSS never loaded, which almost always means the page was opened from a
different folder depth. Confirm the address starts with
http://localhost/repo001/  and not http://localhost/pages/ .


WHICH PAGES NEED SERVER, WHICH DO NOT
-------------------------------------
  index.html                  plain HTML + JS      works from file:// too
  pages/dashboard.html        plain HTML + JS      reads api/*.php for the numbers
  pages/occupants.php         PHP + MySQL          server only
  pages/register-occupant.php PHP + MySQL          server only
  pages/edit-occupant.php     PHP + MySQL          server only
  pages/404-page.html         plain HTML           works anywhere

Only the three PHP screens truly require Apache. They are the ones that
produce the "source code" screenshot when opened as files.
